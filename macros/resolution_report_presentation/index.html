Draft plot-specific choices

Run and era textInfer Run 2 versus Run 3 from the dataset; include the year/era and prompt or UL tag where supported by the input metadata.
Calibration and gainUncalibrated and Gain1Only are defaults and need no label. Mark “Chronus” only for Chronus-calibrated fit inputs; mark “AllGains” only when that selection is used.
Shared display rangesAll plots use y = 0.04–4 ns. Run 2 Gain1Only x = 15–1600; Run 3 AllGains x = 15–3200; ECAL DPG x = 15–800, all logarithmic. These are display limits only; fit inputs and parameters are unchanged.
Pad geometry13.2×9 canvas: 4:3 legacy overlay widened by 10% in the x direction, with TDR frame margins (left 0.15, right 0.05, top 0.09, bottom 0.12). Helvetica-style sans serif (Helvetica, matching the legacy ROOT font choice) is used for text and math labels. Two-line subtitles remain inside the plot body, shifted left and halfway up toward the pad top; year and PD appear first, followed by the sample/selection on the second line. Subtitle and legend text share a font size. In-plot annotation and legend text use about 1.75× the baseline size, parameter rows sit just above the x axis and use a consistent total count of printed digits (decimal point excluded): N 4/3, S 3/3, C 5/5 (value/error), including zero placeholders; legend labels are bold. Header and axis titles remain at 1.25×. The y-axis maximum is 4 ns; y labels show 1–5 subdivisions per log decade while 6–9 labels are suppressed. The minimum x label is hidden and both axis maxima remain labeled.
Run 3 era overlaysStart from the reference's EB/EE and Chronus/default comparison when the records form a matched set.
ECAL DPG additionDedicated EB-only overlay of SRO, DRO, and ZEE using Gain1Only inputs; uncalibrated is the default. For every tail-excluded fit, high-energy points inconsistent with the fit body are excluded from the fit and remain visible as crosses in their original series colors. The fit procedure is described below the plot, not in the legend.
Fit annotationsThese prototypes use the report tail-selection result for each row: when accepted, high-energy points inconsistent with the fit body are excluded from the body-only NSC fit and shown as crosses in their original series color; otherwise, the inclusive NSC fit is used. Parameter rows label each value and uncertainty in [ns]; the fit equation uses stacked fractions. The selected values and uncertainties for all 240 rows are listed in fit_selection_audit.csv.
